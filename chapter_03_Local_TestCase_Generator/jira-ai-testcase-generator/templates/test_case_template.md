# Test Case Template

Generate test cases for the feature described in the Jira requirements.

| Test ID | Description | Pre-conditions | Steps | Expected Result | Priority |
|---------|-------------|----------------|-------|-----------------|----------|
| TC-001  |             |                |       |                 |          |

## Guidelines

- Test ID: `TC-NNN` (sequential).
- Description: what is being verified.
- Pre-conditions: required state before testing.
- Steps: numbered actions.
- Expected Result: the observable outcome.
- Priority: High / Medium / Low.

## Constraints

- Use ONLY the provided Jira requirements.
- Do NOT assume undocumented behavior.
- If information is missing, write "Not specified".
- Cover positive and negative scenarios.
- Include boundary cases only where supported by the requirements.
